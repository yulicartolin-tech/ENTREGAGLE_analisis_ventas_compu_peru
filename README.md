Análisis de Ventas de Suministros de Cómputo en el Perú

Este proyecto fue desarrollado como parte del curso Módulos y Paquetes para Machine Learning con Python.
El objetivo es aplicar herramientas básicas de análisis de datos utilizando Python para explorar información de ventas de productos de cómputo en distintas ciudades del Perú.

¿De qué trata el proyecto?

En este trabajo se crea y analiza un conjunto de datos que representa ventas de productos tecnológicos como laptops, mouse, teclados y monitores.

A partir de estos datos se realizan diferentes procesos como:

* manipulación de datos
* cálculos estadísticos
* filtrado de información
* generación de gráficos para visualizar los resultados

El propósito es comprender cómo los datos pueden ayudar a identificar patrones de venta y obtener conclusiones útiles.

Herramientas utilizadas

El proyecto fue desarrollado en *Python* utilizando tres librerías importantes en el análisis de datos:

Pandas→ para organizar y manipular los datos
NumPy → para realizar cálculos numéricos y estadísticos
Matplotlib→ para generar gráficos que permitan visualizar la información

Qué hace el programa

El programa realiza varias etapas de análisis:

1. Crea un dataset de ventas de productos de cómputo.
2. Calcula el total de ventas por producto.
3. Obtiene estadísticas como promedio, máximo, mínimo y total de ventas.
4. Filtra información para analizar casos específicos.
5. Genera gráficos que ayudan a interpretar los datos de forma visual.
6. Crea un dataset más grande con datos simulados para ampliar el análisis.

Visualización de datos

El programa genera diferentes tipos de gráficos para representar la información:

* gráfico de barras
* gráfico de línea
* gráfico de pastel
* histograma
* gráfico de dispersión
